# Espeletia AI · Álbum del Páramo

Asistente offline para visitantes del PNN Los Nevados: un álbum de cromos que se gana mirando el páramo. Es una app web instalable (PWA) que funciona en modo avión, reconoce el paisaje con un modelo pequeño dentro del celular (MobileNetV2 + k-NN) y solo muestra información oficial con fuente.

- **Probarla en un computador:** dentro de esta carpeta corre `python3 -m http.server 8000` y abre `http://localhost:8000/?demo`.
- **Publicarla:** cualquier hosting estático con HTTPS (GitHub Pages, Netlify).

La guía completa (instalación, Modo equipo, calibración, pruebas y estructura) está en [LEEME.md](LEEME.md).
